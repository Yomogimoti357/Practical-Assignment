PROJECT PLAN / SUMMARY

BODY
AS INPUT

目的
Webカメラから取得したプレイヤーの身体情報をゲーム入力として利用し、キーボードやマウスによる通常操作と組み合わせることで、現実の身体状態がゲーム内の出来事へ直接影響する体験を実現します。
コンセプト
カメラ映像を表示するためではなく、プレイヤーの存在、位置、移動量、姿勢の変化、静止状態などを取得するインターフェースとして扱います。
処理構成
「映像取得・身体情報認識・動作判定・ゲーム内反応」を分離し、複数フレームの結果から一時的なノイズや照明変化による誤判定を抑えます。
プレイ体験
通常操作で探索し、身体入力が必要な状況へ対応し、その判定結果によってイベントや画面・音響が変化する流れを、ゲーム全体の基本ループとして構築します。
完成目標
カメラ設定、エラーからの復帰、状態管理、UI、演出を統合し、開発環境以外のPCでも初回起動から終了まで進行できる完成版を目指します。
